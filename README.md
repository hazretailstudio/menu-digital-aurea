# Café & Bistro Áurea — SaaS POS & KDS v2

## Archivos incluidos
- `index.html` + `js/menu-main.js`: Menú QR Interactivo para comensales.
- `admin.html` + `js/admin-main.js` + `js/modules/*.js`: Panel Operativo completo (Mesas, KDS por Estación, Caja/Cortes X-Z, Carta/Botón 86/Modificadores, Promociones, Inventario, Gerencia y PINs).
- `migration_v2.sql`: Script **seguro** para actualizar tu Supabase actual sin borrar tus datos.
- `schema.sql`: Script completo solo si quieres reiniciar toda la base desde cero.
- `vercel.json`: Configuración de despliegue sin caché.
